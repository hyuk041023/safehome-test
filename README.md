# Safe Home MVP (규칙 기반 · AI 없음)

충북대 근처 자취방을 추천하고, 계약 전에 위험 신호를 점검하는 시연용 MVP예요.
노션의 **MVP 설계 (초안)**, **11/10 설문 가중치**, **11/11 회의 제안(예시 계약서 불러오기)**을 바탕으로 만들었어요.

> 매물·계약서·등기·시세는 모두 **가상 샘플 데이터**예요. 실제 개인정보는 없어요.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py        # safehome.db가 없으면 자동으로 만들어요
python test_mvp.py          # 규칙 검증 테스트
python db_seed.py           # DB를 처음부터 다시 만들 때
```

- **Streamlit Cloud**: 이 저장소를 연결하고 진입 파일을 `app.py`로 지정하면 돼요.
- **Vercel**: 이 저장소를 Import하면 `index.html`이 stlite로 같은 Streamlit 앱을 브라우저 안에서 실행해요 (빌드 설정 없음, 첫 로딩 20~40초).

## 화면 3개 (시연 5장면)

| 화면 | 하는 일 |
| --- | --- |
| ① 집 찾기 | 문장 입력 → **규칙으로 해석**해 입력칸 자동 채우기 → 사용자가 확인·수정 |
| ② 추천 결과 | 적용된 조건 태그, 필수 조건 필터, 설문 가중치 정렬, 진짜 한 달 비용, 샘플 시세 비교, **계약 전 확인할 것 배지**, 점수 내역 |
| ③ 계약 점검 | DB의 **텍스트 가상 계약서·등기**를 불러와 표시(수정 가능) → 8개 항목 점검 → 근거 문구 → 물어볼 질문 → 문자 초안 |

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `app.py` | Streamlit 화면 |
| `recommend.py` | 문장 해석(정규식), 필터, 설문 가중치·ROC 혼합, 점수, 시세 비교 |
| `contract_check.py` | 텍스트 계약서·등기 읽기, 8개 항목 규칙, 특약 키워드 분류, 질문·문자 초안 |
| `db_seed.py` | SQLite DB 생성 (매물 40건, 계약 사례 10종) |
| `test_mvp.py` | 사례별 기대 판정·가중치·필터 테스트 |

## DB 구조 (`safehome.db`)

- `listings` — 가상 매물 (보증금, 월세, 관리비, 넓이, 채광·조용함 1~5, 옵션, 정문·중문·후문 도보 시간, 사례 ID)
- `contracts` — 매물별 **계약서 원문 텍스트** (`contract_text`)
- `registries` — 매물별 **등기 요약 원문 텍스트** (`registry_text`)
- `cases` — 사례 10종과 기대 판정 (검증표)
- `market_prices` — 동·유형별 샘플 시세 (실거래가 API 연결 전 임시값)

## 계약 점검 규칙

모든 항목은 **정상 / 주의 / 위험 / 확인 필요** 중 하나예요. 문서에 값이 없으면 추측하지 않고 **확인 필요**로 보내요.
종합 판정은 가장 나쁜 항목을 따르고, 확인 필요가 남아 있으면 "양호"라고 하지 않아요.

| 항목 | 기준 |
| --- | --- |
| 임대인·소유자 일치 | 불일치 🔴, 위임장 있는 대리인 🟡, 신탁회사 소유 🔴 |
| 보증금 회수 위험 비율 | (근저당 채권최고액 + 선순위 보증금 + 내 보증금) ÷ 시세 — 70% 🟡, 80% 🔴 |
| 압류·가압류 | 있으면 🔴 |
| 신탁 등기 | 있으면 🔴 |
| 임차권등기 | 있으면 🟡 |
| 최근 소유권 이전 | 계약 작성일 기준 90일 이내 🟡 |
| 납세증명서 | 미확인 🟡 |
| 특약 | 전입신고 제한·보증금 반환 지연·담보 추가 허용 🔴 / 수리비 전가·과도한 원상복구·중도 해지 위약금 🟡 |

## 사례 10종 (테스트로 검증됨)

| 사례 | 상황 | 기대 판정 |
| --- | --- | --- |
| A | 정상 계약 | 큰 위험 신호 없음 |
| B | 임대인·소유자 불일치 | 위험 신호 있음 |
| C | 보증금 회수 위험 비율 88% | 위험 신호 있음 |
| D | 근저당·선순위·압류·납세 정보 없음 | 확인 후 판단 |
| E | 전입신고 제한 + 새 임차인 입주 후 반환 특약 | 위험 신호 있음 |
| F | 신탁 등기 | 위험 신호 있음 |
| G | 30일 전 소유권 이전 + 임차권등기 | 주의 필요 |
| H | 비율 73% + 모든 수리비 임차인 부담 | 주의 필요 |
| I | 위임장 있는 대리인 계약 | 주의 필요 |
| J | 압류 등기 | 위험 신호 있음 |
